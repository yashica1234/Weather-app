# 🌤️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript**.
It uses the **OpenWeather API** to fetch and display real-time weather information for a searched city.

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Displays current temperature
* 💧 Displays humidity
* 💨 Displays wind speed
* 🌦️ Changes weather icon according to weather condition
* ❌ Shows an error message for an invalid city
* 📱 Responsive and clean UI

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* OpenWeather API

## 🚀 How It Works

1. Enter a city name in the search box.
2. Click the search button.
3. JavaScript sends a request to the OpenWeather API.
4. The API returns the weather data.
5. The application updates the temperature, humidity, wind speed, city name, and weather icon.

## 🔑 API

This project uses the **OpenWeather API** to retrieve weather data.

The API key is kept private and is not included in the GitHub repository.
